# Galaxy Genome Web 查询器

静态网页，从指定中心搜索范围内最近的游戏恒星或行星。搜索同时覆盖真实恒星、固定行星系统和匿名程序生成星系。

## 运行

在仓库根目录执行：

```powershell
python -m http.server 8080 -d web
```

然后访问 `http://localhost:8080/`。

## 查询方式

- 中心点必须使用星系名称或 X/Y 光年坐标，两种方式任选其一。
- 名称对真实星系执行精确、不区分大小写匹配；程序名称会规范化大小写并验证实际生成位置。
- 搜索半径为 `1-2000 ly`，每次选择一种行星类型或一种恒星类型。
- 结果严格按二维光年距离返回最近 10 条。行星和多星系统中的每颗恒星分别计为一条结果。
- `排除固定行星系统` 默认开启；`排除具名真实星系` 默认关闭。排除项不影响星系作为搜索中心。
- 原游戏轴线名称可能对应两个有效位置，页面会显示两个光年坐标供选择。
- 地图内部保留游戏坐标用于绘制，界面文字只显示光年坐标。
